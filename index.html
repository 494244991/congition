录入新内容

选择主题 → 填写标题与正文 → 提交即发布

想让所有人都能看到你录入的内容？点右上角「⚙ 设置」填入 GitHub Token 即可（无需后端，直接写入仓库 content/）。 若已部署 Cloudflare Pages 并提交接口，也会自动走服务端。 两者都未配置时，内容仅暂存本浏览器（localStorage），可用「导出录入内容」下载备份后合并。

投稿设置（开启多人共享）

填入后，点「提交发布」会直接写入 GitHub 仓库的 content/ 目录， 所有人刷新页面即可看到（GitHub Pages 约 1 分钟重建）。 Token 仅保存在你当前浏览器，不会上传到任何服务器。
